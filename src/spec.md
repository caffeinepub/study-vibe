# Specification

## Summary
**Goal:** Update the app branding to “Study Vibe”, add full-page English/Hindi language switching, and enhance each subject card with a dedicated illustrative subject image.

**Planned changes:**
- Rename all user-visible branding and page metadata from “Study Vibes Class 9” to “Study Vibe” (header text and HTML document title included).
- Add Hindi translations for all subject titles and subject summary content, plus translated navigation labels.
- Add a language toggle (English/Hindi) that switches the displayed language across the entire page (navigation, subject card titles, subject content, and image alt text).
- Add and display 7 subject-specific illustrative images (one per subject) within each subject card using a consistent, responsive layout, sourced from `/assets/generated/`.
- Update the existing generated logo and hero/banner images to reflect the renamed “Study Vibe” branding while keeping the warm academic theme, ensuring no broken asset references.

**User-visible outcome:** The site shows “Study Vibe” branding, users can switch between English and Hindi for all displayed subject/navigation text, and each subject card includes a distinct illustrative image that looks good across screen sizes.
